# Nullary

A research project exploring how division by zero can be treated consistently inside a formal axiomatic system.

## Overview

Nullary investigates whether expressions involving division by zero can be given meaning without collapsing the entire arithmetic system into inconsistency. The work focuses on building a structured alternative to classical field axioms and examining how this impacts symbolic reasoning.

## Key ideas

- Define a controlled extension of arithmetic where division by zero is expressed through a new symbolic operator.
- Preserve as many algebraic identities as possible while isolating undefined behavior.
- Explore the boundary between conventional mathematics and alternative formal systems.

## Outcomes

- A modular notation for conditional division behaviors.
- Examples showing how the extended system can still support reasoning about limits and symmetry.
- A project write-up that bridges conceptual explanation and symbolic derivation.
